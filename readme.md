# admin-agent

A personal CLI assistant that answers administrative questions and automatically saves structured notes to an Obsidian vault.

## What it does

- Takes a question from the terminal
- Searches your Obsidian vault for relevant context
- Calls Claude (Anthropic) to generate a structured action plan
- Saves the response as a formatted Markdown note in your vault

## Stack

- Python 3.14
- [Anthropic SDK](https://github.com/anthropic/anthropic-sdk-python)
- Obsidian (local Markdown vault)

## Setup

**1. Clone the repo**
```bash
git clone https://github.com/YOUR_USERNAME/ai-obsidian-agent.git
cd ai-obsidian-agent
```

**2. Create a virtual environment**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**3. Configure environment variables**
```bash
cp .env.example .env
```

Edit `.env` with your values:

ANTHROPIC_API_KEY=your_key_here
VAULT_PATH=/path/to/your/obsidian/vault


**4. Run**
```bash
python3 agent.py
```

## Project structure

.
├── agent.py        # core logic and Claude integration
├── obsidian.py     # vault read/write operations
├── config.py       # environment variable loading
├── requirements.txt
└── .env.example


## Notes

Each answer is saved as a Markdown file in the `Admin/` folder of your vault, with a title generated by the model based on your question.
